فرش دسکتاپ (Desktop Rug) — ویندوز ۱۰ و ۱۱
==========================================

نصب و فعال‌سازی (یک بار):
  ۱. کل این پوشه را از zip بیرون بیاورید (Extract All).
  ۲. روی «فعال‌سازی فرش.bat» دوبار کلیک کنید (یا Enable-DesktopRug.bat).
     برنامه در %LOCALAPPDATA%\DesktopRug کپی می‌شود، به اجرای خودکار ویندوز اضافه می‌شود
     و همان لحظه روی دسکتاپ ظاهر می‌شود. به دسترسی Administrator نیازی نیست.
  (اگر مستقیم روی DesktopRug.exe دوبار کلیک کنید هم بار اول خودش همین کار را می‌کند.)

از این به بعد فرش بعد از هر خاموش/روشن کردن یا ری‌استارت خودش اجرا می‌شود.
اگر برنامه را از منو «خروج» کنید یا برنامه بسته شود، اجرای خودکار غیرفعال نمی‌شود.
اگر فایل دانلودشده را پاک یا جابه‌جا کنید هم مشکلی نیست؛ نسخه‌ی نصب‌شده اجرا می‌شود.

خاموش کردن:
  روی «غیرفعال‌سازی فرش.bat» دوبار کلیک کنید (یا Disable-DesktopRug.bat).
  فرش بسته می‌شود و دیگر با ویندوز اجرا نمی‌شود. تنظیمات (جا، اندازه، طرح) می‌ماند.
  یک نسخه از همین فایل‌ها در %LOCALAPPDATA%\DesktopRug هم هست.

روشن کردن دوباره: «فعال‌سازی فرش.bat».
حذف کامل (برنامه + تنظیمات): «حذف کامل فرش.bat» (یا Uninstall-DesktopRug.bat).

کار با فرش:
  • هر نقطه از فرش را بگیرید و بکشید تا تا شود؛ روی فرش تاشده کلیک کنید تا صاف شود.
  • جابه‌جایی: کلید وسط ماوس، یا Ctrl + کشیدن، یا نگه داشتن و کشیدن.
  • تغییر اندازه: Ctrl + کشیدن لبه.  چرخاندن: Shift + کشیدن.
  • کلیک راست روی فرش یا آیکون کنار ساعت: منو
      - «طرح فرش»: چهار طرح آماده (تبریز، کاشان، نائین، قشقایی) یا عکس دلخواه
      - «پس‌زمینه»: عوض کردن والپیپر ویندوز (پارکت روشن، چوب تیره، کاشی سنگی، موکت،
        یا عکس دلخواه) و «برگرداندن پس‌زمینه‌ی قبلی»
      - «اجرا با سیستم»: روشن/خاموش کردن اجرای خودکار

نکته: فایل امضای دیجیتال ندارد؛ اگر SmartScreen هشدار داد: More info ← Run anyway.

---------------------------------------------------------------------------
English: Extract the folder. Double-click Enable-DesktopRug.bat to install for
this user (no admin), start with Windows and start now. Double-click
Disable-DesktopRug.bat to close it and stop autostart (settings are kept).
Uninstall-DesktopRug.bat removes the app and its settings.
